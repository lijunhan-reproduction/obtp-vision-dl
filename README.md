# OBTP-Vision-DL

This repository contains the code and aggregated experimental results for the paper:

**Oracle-Free Test Prioritization for Vision-Based Deep Learning Systems via Bayesian Optimization with Constrained Bandit Allocation**

## Contents
- `src/`: main implementation
- `scripts/`: utilities for running experiments and plotting figures
- `results/`: aggregated experimental results used in the paper
- `figures/`: paper figures
- `data/`: notes on dataset access and structure

## Datasets
This study uses publicly available datasets, including:
- CIFAR-10
- Fashion-MNIST
- ISIC2019

The original datasets should be obtained from their official sources.

## Reproducibility
This repository provides the implementation and aggregated results needed to reproduce the main findings reported in the paper.
